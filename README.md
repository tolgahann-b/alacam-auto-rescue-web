# 🚜 Alaçam Gül Oto Kurtarma - Kurumsal Web Projesi

Bu proje, yerel bir işletme olan "Alaçam Gül Oto Kurtarma" için uçtan uca tasarlanmış ve yayına alınmış ticari bir web sitesidir. Tasarımda modern web standartları gözetilmiş olup, tüm cihazlarda (mobil, tablet, masaüstü) %100 uyumlu (responsive) çalışması sağlanmıştır.

### 🔴 Canlı Yayında İnceleyin:
**👉 [Sitenin Canlı Haline Gitmek İçin Tıklayın](https://alacamgulotokurtarma.com/)**

### 🛠️ Kullanılan Teknolojiler
* **HTML5:** Semantik web standartlarına uygun iskelet yapısı.
* **CSS3:** Özelleştirilmiş stil tasarımları.
* **Bootstrap:** Hızlı, esnek ve responsive grid (ızgara) mimarisi.

### 💡 Proje Hakkında Notlar
* Proje tamamen müşteri talepleri doğrultusunda, ticari bir amaca hizmet edecek şekilde kodlanmıştır.
* Sitenin alan adı (domain) yönlendirmeleri ve barındırma (hosting) işlemleri tarafımca yönetilerek canlıya alınmıştır.
